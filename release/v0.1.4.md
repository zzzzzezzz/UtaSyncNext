# UtaSyncNext v0.1.4：新电脑也能准备人声分离

这版补上了唱歌视频所需的 Demucs 权重下载入口。新电脑安装 Next 引擎后，打开“引擎与模型管理”即可看到“人声分离权重”的状态；缺少时点击“下载/准备权重”，下载完成后会显示“已就绪”。

## 这次改了什么

- 可以在软件内下载 `htdemucs_ft` 的 4 个权重文件。下载使用当前代理设置，网络中断后可继续，完成后会校验文件。
- “本机体检”会分别报告引擎、FFmpeg 和人声分离权重的状态，避免引擎已安装却在唱歌任务中因缺权重而停下。
- 修正了自定义 Next 引擎目录下的 Demucs 权重定位。
- 引擎分卷未变，继续使用 v0.1.3 的 Cloudflare R2 文件；本次仅更新基础包和 GitHub 上的引擎清单附件。

## 新电脑使用顺序

1. 下载 `UtaSyncNext-basic-v0.1.4.zip`，完整解压后运行 `UtaSyncNext.exe`。
2. 打开“引擎与模型管理”，按需填写代理，点击“安装 Next 引擎”；安装完成后重启软件。
3. 下载要用的 Faster-Whisper 模型。
4. 做唱歌视频时，点击“人声分离权重”区域的“下载/准备权重”，等状态变为“已就绪”。访谈/播客可跳过这一步。
5. 确认本机有 `ffmpeg` 和 `ffprobe`，然后开始任务。

Demucs 权重约 337 MB，保存在当前软件目录的 `.cache/torch/hub/checkpoints/`，不随基础包分发。换电脑时在新电脑上执行第 4 步即可。
