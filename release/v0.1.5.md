# UtaSyncNext v0.1.5：修复新电脑的 HTTPS 下载

这版修复了部分新电脑打开“引擎与模型管理”时出现 `CERTIFICATE_VERIFY_FAILED`、无法读取引擎下载清单的问题。

## 这次改了什么

- 引擎清单下载和 Demucs 人声分离权重下载现在会使用 Windows 信任根，以及随基础包提供的 CA 证书。
- 普通直连和 HTTP 代理不需要用户手动配置 Python 证书。
- 仍然保留代理设置和 HTTPS 证书校验，不会为了绕过错误而关闭安全校验。
- 引擎分卷和 R2 地址不变，不会重复上传旧引擎文件。

## 新电脑使用

1. 下载并完整解压 `UtaSyncNext-basic-v0.1.5.zip`。
2. 打开“引擎与模型管理”，点击“重新检查资源”。
3. 安装 Next 引擎并重启软件。
4. 下载需要的 Faster-Whisper 模型；做唱歌视频时，再下载 Demucs 人声分离权重。

如果所在网络使用 HTTPS 中间人代理，程序无法安全地自动信任一个未知根证书。此时应清空代理重试、改用普通 HTTP CONNECT 代理，或使用已把网络根证书加入 Windows 信任存储的网络；不要关闭证书校验。

## 校验信息

基础包 SHA256 会随 Release 页面提供。引擎清单和外置引擎分卷沿用已验证版本，R2 不需要重新上传。
